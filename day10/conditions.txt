conditional  statements
------------------------
1.simpleif
    The if statement is used to check a condition.
    If the condition is True, the code inside if is executed.
    If the condition is False, the code is skipped.
2.if else
    if-else is used for decision making.
    if checks a condition.
    If the condition is True, the if block executes.
    If the condition is False, the else block executes.
    Only one block will execute.   
3.elif ladder
    elif means else if.
    It is used to check multiple conditions.
    Conditions are checked from top to bottom.
    When one condition becomes True, its block executes.
    The remaining conditions are skipped.
    else executes when all conditions are False.
4.nested if 
    Nested if means an if statement inside another if statement.
    It is used when we need to check a second condition after the first condition is true.
    The inner if executes only when the outer if condition is True.
------------------------------------------------------------

    #statements

if condition:
    #statement is true
else :
    #statement is False
